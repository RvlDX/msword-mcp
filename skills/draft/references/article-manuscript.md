# Drafting a journal or conference manuscript

Use this reference for articles, not theses or internship reports. Follow target venue instructions before generic structures.

## Workflow
1. Identify article type and target venue (original research, review, conceptual, case report, protocol, or other).
2. Record required section order, length, reference style, abstract, tables/figures, and declarations from author instructions.
3. Map purpose/question to contribution, methods or argument, results/evidence, and conclusion.
4. Build a section outline; use IMRaD only when suitable.
5. Draft one section at a time from author material and verified sources.
6. Distinguish actual findings from planned or expected work.
7. Verify citations and source metadata while drafting.
8. Align title, abstract, keywords, tables, figures, and declarations with the completed manuscript.
9. Run the article audit module before calling the manuscript submission-ready.

Review and conceptual articles use a transparent search, selection, synthesis, or argument structure instead of forcing empirical Methods/Results.

Use E/C/A/P/U labels from `../../shared/workflow-contract.md`. Never invent findings, participant counts, tests, or publication metadata.
