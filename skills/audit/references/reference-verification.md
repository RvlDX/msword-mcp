# Reference and citation verification

Verify sources according to type. Never require a DOI for sources that do not normally have one. Never guess authors, year, DOI, volume, issue, pages, publisher, or access date.

| Source type | Preferred verification evidence |
|---|---|
| Indonesian journal | Article/journal page, Garuda, or SINTA; verify title, authors, journal, ISSN, year, volume/issue, pages, DOI if assigned |
| International journal | Publisher page, Crossref, OpenAlex, or DOI resolver; verify article metadata and DOI if assigned |
| Conference paper | Proceedings/publisher record |
| Book/chapter | Publisher or library catalog; inspected title/copyright page |
| Thesis/dissertation | Institutional repository or library record |
| Law/standard/regulation | Official issuing body or official publication |
| Organization/government report | Official organization source or inspected report |
| Dataset | Original repository, issuing organization, version, date, license, data dictionary |
| Official web page | Official URL, title, issuing body, date, and access date |
| Interview/observation/internal record | Authorized record, context/date, and consent/access status |

Prefer the publisher or issuing body for authoritative metadata. Discovery services do not prove every bibliographic field.

## Citation audit
- In-text citations match reference entries when the style requires a reference list.
- Every entry is cited unless the style permits uncited bibliography.
- Metadata matches the verified record; missing fields are marked for verification.
- Direct quotations match the inspected source. Do not claim quote verification without full source access.
- Citation style follows the current guide or target publication.

## DOI handling
If a DOI exists or is claimed, verify it resolves and matches the source. If no DOI is assigned, do not fail the source. A non-resolving supplied DOI is UNVERIFIED. Never infer or construct a DOI.

## Recency
Apply the time window in the applicable guide or venue instructions. Do not impose a universal five- or ten-year limit. Record distinct windows for distinct source categories.

## Verification record
For uncertain references record citation/location, source type, verified fields, URL/local file, missing/conflicting fields, and status (verified/partial/unverified/inaccessible). A search-result snippet alone is not verification.
