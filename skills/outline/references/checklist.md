# Checklist

Run the universal part (U) for every document, then the genre checks from the genre file used. Report as a table with item, status, and fix. Never write "all passed" without the table.

Only three statuses are allowed.

- Pass: fulfilled.
- Waiting for data: structure is right, but it needs `[NEED: ...]` from the user. Titles may be given with the label provisional.
- Fail: structure is wrong. Fix the outline first.

## U. Universal

| # | Item | How to check |
|---|---|---|
| U1 | Specific reader | The reader can be named in one phrase that is not "everyone" or "general" |
| U2 | Real gap | Should and Is differ, and Is has a basis (data, observation, complaint) or `[NEED: ...]` |
| U3 | Core claim in one sentence | A person outside the field understands the sentence |
| U4 | No orphans | Every question, promise, or claim leads to a section that answers it, with evidence or `[NEED: ...]` |
| U5 | No section without a job | Every section has a Job line serving U3 or U4 |
| U6 | Order follows the reader needs | Read only the section titles from top to bottom: the flow makes sense without the content |
| U7 | No overlap | Two sections do not answer the same thing (mutually exclusive, collectively exhaustive) |
| U8 | Clear final action | The reader knows what to do or conclude |
| U9 | Zero invented facts | Every number, name, quote, and source comes from the user or is marked `[NEED: ...]` or `[CHECK: ...]` |
| U10 | External rules marked | Campus guide, client format, or regulation is marked `[CHECK: ...]` when unconfirmed |
| U11 | Realistic length | The length hints of the sections fit the total limit |
| U12 | Title from the core claim | Written last, promises no more than the content delivers |
| U13 | Consistent inside one document | Counts (phases, stages, hypotheses, respondents) and names (institution, program, component, supervisor) are the same in every part: cover, approval, abstract, content, diagram, schedule. A difference is marked `[CONFLICT]` |
| U14 | Lists in sync with content | Table of contents, figures, tables, and appendices match the content in numbers and titles |
| U15 | Content matches the section title | For mandatory sections, read the content, not only the title |

## Fast mode

For Quick mode run U1, U2, U4, U8, U9, U13, plus every check of the genre file. Genre checks are never skipped.

## Most common failures and fixes

| Symptom | Cause | Fix |
|---|---|---|
| Long background but the problem statement does not connect | Gap not formulated | Rewrite Step 1, then derive the formulation from the Gap |
| Supervisor: the title is too broad | Title written before the outline | Go back to A1, narrow the object, location, or variables |
| Chapter 4 does not answer the formulation | Orphan | Build a table of formulation to data to analysis to subchapter |
| A mandatory appendix cannot be produced anymore (photo, signature, log) | Appendices only thought of after the activity ended | Plan the appendices at the start, with a column for when each is collected |
| Campus template differs from the outline given | Guide variables not filled at the start | Run the 14 variables in guide-adapter.md before outlining |
